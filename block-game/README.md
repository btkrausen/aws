# Block Game

A simple Tetris-style block game implementation in Python. This project demonstrates basic game logic, including piece movement, rotation, collision detection, and line clearing.

## Project Overview

This is a command-line Tetris game that allows players to control falling tetromino pieces. The game includes:

- **tetris.py** - Main game file with complete Tetris implementation
- Classic Tetris mechanics (piece movement, rotation, line clearing)
- Score tracking
- Simple text-based interface

## Prerequisites

- **Python 3.x** - The game requires Python 3 or higher
- No external dependencies required (uses only Python standard library)

## How to Run

To play the game, simply run the following command from the `block-game` directory:

```bash
python3 tetris.py
```

### Game Controls

Once the game starts, use the following commands:
- `a` - Move piece left
- `d` - Move piece right
- `s` - Move piece down
- `w` - Rotate piece
- `q` - Quit game

Press Enter after each command to execute it.
